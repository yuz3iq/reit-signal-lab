# Ritz Signal Lab

국내 상장 오피스 리츠 5종(삼성FN리츠·한화리츠·코람코더원리츠·NH프라임리츠·신한알파리츠)의 RBF 커널 SVR 워크포워드 예측 모델을 실시간으로 서빙하는 백엔드.

- `/` — 대시보드 (정적 백테스트 결과 + 오늘의 라이브 시그널)
- `/api/bundle` — 워크포워드 백테스트·몬테카를로 검증 결과(정적, 2026-09-16 기준)
- `/api/live` — 네이버 금융에서 최근 시세를 가져와 트레일링 90거래일로 모델을 재학습하고, 내일 예측 시그널을 계산 (15분 캐시)

원 논문: 장유리·차형현, "RBF 커널을 활용한 오피스 리츠 수익률 예측 모델의 구현", Ritz, 2026.
