국내 상장 오피스 리츠 5종 · RBF 커널 예측모델 실전 검증

논문 속 R²=0.59, 실전에서도 통했을까

“RBF 커널을 활용한 오피스 리츠 수익률 예측 모델”(2026)이 보고한 설명력을, 5개 종목의 실제 시세로 진짜 워크포워드(out-of-sample) 방식으로 다시 학습시키고, 그 신호로 실제 매수/현금 전략을 백테스트한 뒤, 몬테카를로 무작위 신호와 비교해 그 우위가 우연인지 실력인지까지 검증했습니다.

Methodology

원 논문과 다르게 검증한 3가지

같은 RBF-SVM 롤링윈도우 아이디어를, 더 엄격한 3단계로 다시 통과시켰습니다.
01 — 워크포워드 검증

매일 재학습, 미래 정보 0%

90거래일 롤링 윈도우로 매일 모델을 재학습해 “하루 뒤” 수익률만 예측. 학습에 쓰인 정보는 예측 시점까지 것뿐입니다.

02 — 시그널 백테스트

예측을 실제 매매로 전환

예측 수익률 부호(+/−)를 매수/현금 시그널로 바꿔 개별 종목 & 포트폴리오 성과를 코스피·단순보유와 비교했습니다.

03 — 몬테카를로 유의성 검정

운이 아니라 실력인가

같은 비중으로 동전을 던지는 무작위 신호 2,000회와 비교해, 모델의 성과가 우연의 분포 어디에 위치하는지 계산했습니다.

Scoreboard

Detail

상세 분석

누적 성과, 변수 기여도, 무작위 신호 대비 위치를 종목별로 뜯어봅니다.

누적 성과 — 전략 vs 단순보유

변수 기여도 (순열 중요도)

테스트 구간에서 각 변수를 무작위로 섞었을 때 예측력(R²)이 얼마나 떨어지는지. 0에 가까울수록 “그 변수는 큰 역할이 없었다”는 뜻입니다.

몬테카를로 검정

무작위 신호 2,000회의 샤프지수 분포. 굵은 선이 모델의 실제 위치입니다.
